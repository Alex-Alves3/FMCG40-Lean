# FMCG40-Lean

A Lean 4 formalisation of the FMCG 4.0 framework's Signal-to-Shelf (StS) metric and Coupling Benefit Ratio (CBR), as defined in Alves and Treleaven (2026), "FMCG 4.0 and Signal-to-Shelf Analytics." This repository provides machine-checked proofs of the abstract mathematical properties of the framework — monotonicity of Signal-to-Shelf in elapsed time, well-definedness of the metrics, and conditions under which integrated decision-making yields a Coupling Benefit Ratio at or above 1 — as part of a UCL Computer Science PhD thesis.

## Status

Numerical verification against the paper's Appendix 2 (ChillZen case study) is currently not included.
